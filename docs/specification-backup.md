# 制作规范本地备份

Admin 可在 `/admin/specifications` 上传 PDF、DOCX、Markdown 或纯文本制作规范。文件存放在运行目录的 `specifications/` 下，数据库只保存版本号、标题、原文件名、SHA-256、上传者、时间和当前版本标记。运行目录位于被忽略的 `var/`，文件及数据库都不得提交 Git。

- 只有 Admin 可以上传、下载和切换当前版本；Viewer 无权访问。
- 同一 SHA-256 重复上传返回已有版本，不复制第二份文件。
- 切换当前版本只改变备份元数据，不回写历史报告。
- 规范备份不进入 PDF 文本提取、映射、质量闸门或发布判断；缺少规范文件也不阻止每日报告上传。
- `real_local`、fixture demo 与测试数据库相互隔离。

这是操作留档功能，不是解析提示词或业务规则热更新机制。修改解析规则仍须通过代码、配置、测试和人工验收。

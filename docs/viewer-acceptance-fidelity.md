# Viewer验收保真口径

Viewer 只读取 `published` 报告。主导航固定为“最新报告 / 报告库 / 板块研究 / 管理区”；报告详情使用页面内章节导航，不把详情页错误标记成报告库首页。

历史路径矩阵默认最近20期，可切换10期、20期、40期和全部。矩阵按一级分组保留66个板块，使用 PDF 约定的纯色状态，最新一期有明确边框，桌面端默认滚动到最新列，移动端显示最近5期时间线。点击单元格可查看判断、辅助行情和来源链接。

报告详细汇总直接采用“板块 / 历史路径 / 当期判断 / 主要依据 / 观察条件”五字段结构，主要依据和观察条件在桌面与390px移动布局中始终可读。当期状态只显示一次。Viewer不显示冗长原文摘录；来源页码、文本范围和证据摘要仅在Admin复核区保留。

板块研究页是密集纵向档案表，只保留一个“实时行情”即时列，并将本期/有效、观点/日期、绝对/广义持有期及MA5/MA20分别收进紧凑单元格。完整EOD不单独占列，但继续独立支撑5/10/20日指标、均线、持有期、路径矩阵和冻结快照。数据表使用清晰的系统中文字体栈，表头不逐字竖排。路径历史不要求相应日期的详细PDF全部已上传；详细观点历史只来自已上传且发布的报告。正收益使用红色、负收益使用绿色，但始终同时显示数值。酒店餐饮始终显示代理口径，玻璃基板显示短历史，恒生科技保留直播观点但行情继续为不支持。

报告页面初次加载、刷新和章节切换都不创建PDF iframe。用户点击“加载PDF预览”后才请求服务端内存渲染的分页图片；只有明确点击“下载原PDF”才访问 `attachment` 响应。

离线高保真演示生成20份确定性虚构报告，覆盖2026-06-22至2026-07-19的报告节奏，周五和周六不生成报告。运行文件只允许写入被忽略的 `var/demo-fidelity/`，不得覆盖已有数据库。

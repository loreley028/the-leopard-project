# Provider 风险登记册（Phase 1A 最终版）

| 风险 | 当前控制 | Phase 1B 准入动作 |
|---|---|---|
| 生产 Provider 尚未批准 | 所有角色仅为 `candidate_primary` 或 `diagnostic_provider` | 完成六项生产准入条件后另行批准 |
| 数据使用授权 | 公共网页端点只作诊断，不承担生产角色 | 核实用户账号权限及使用/保存/再分发条款 |
| 公共端点快照倒退 | 提供 `stale_snapshot` 和历史长度异常检测 | 维护已保存水位并拒绝异常快照进入正常链路 |
| `amount` 缺失 | 改为可选，设置 liquidity_status，禁止推算 | 对账确认各 Provider 的真实可用字段 |
| volume 单位差异 | 不跨板块做绝对量排名 | 完成字段与单位合同及转换测试 |
| 玻璃基板短历史 | 标 `history_insufficient`，保留真实数据 | 达到阈值后自动恢复长期指标和完整排名 |
| 酒店口径为代理 | 固定 `881160 + proxy`，不实现881161等权 | 更换口径必须新映射版本和生效日期 |
| 港股日历误用 | HSTECH 固定 HK 市场、Provider 负责代码转换 | 接入正式 HK 日历并做跨市场调度测试 |
| 同源主备失效 | AKShare/公共端点均只作诊断 | 生产主备必须评估上游独立性 |
| 凭证泄露 | 当前适配器不保存 Token，日志不记录凭证 | Token 仅由 secret 注入并持续扫描 Git |

## 是否进入 Phase 1B

仍建议进入受限 Phase 1B，但只包括：Tushare账号权限验证、66代码转换验证、授权字段与单位适配、独立HSTECH/HK日历接入、双源对账和时效性闸门。不得直接开启生产入库、正式调度或部署。
